# Tizen Pult — Android-пульт для Samsung Smart TV (новые и старые)

Пульт для телевизоров Samsung Smart TV — поддерживает **все поколения протоколов**:

- **Tizen 2018+** (проверен на UE43AU9000UXRU, Tizen 6.0, 2021) — `wss://:8002` с токеном;
- **Tizen 2016–2017** — `ws://:8001` без TLS (с автопробой полноценности сеанса:
  старые Orsay-ТВ подключение принимают, но управление отклоняют — тогда идём дальше);
- **Smart TV 2011–2015** — легаси-протокол **TCP 55000** (открытый и зашифрованный AES);
- **Smart View 2.0 (Orsay H-серия 2014 и часть J 2015, напр. UE48H6800)** —
  `socket.io :8000` с AES-шифрованием команд и **PIN-сопряжением** (`:8080`):
  на ТВ показывается 4-значный PIN, после ввода в пульте команды работают.

Протокол определяется автоматически по открытым портам и запоминается для каждого ТВ.
Нюансы новых прошивок учтены: новый протокол ввода текста, правильные имена клавиш,
авторизация токеном, автопоиск ТВ при запуске.

## Скачать готовый APK

Без сборки и Android Studio:

- **Стабильная версия:** [Releases](https://github.com/teliy/Tizen-pult/releases/latest) —
  файл `Tizen-Pult-vX.Y.apk` в разделе Assets;
- **Свежая сборка из ветки main:** вкладка [Actions](https://github.com/teliy/Tizen-pult/actions) →
  последний зелёный запуск → Artifacts → `Tizen-pult-debug`.

Установка: скачайте APK, откройте его на телефоне, разрешите установку из
неизвестных источников. Все сборки подписаны одним и тем же ключом из этого
репозитория (`keystore/debug.keystore`), поэтому обновления ставятся поверх
предыдущих без удаления приложения.

## Возможности

- **экран «Настройки» (v3.1)** — весь «не-пульт» в одном месте: кнопка
  «⚙» в шапке пульта;
- **выбор ТВ прямо на пульте (v3.3)**: выпадающий список в шапке (история
  найденных/сохранённых ТВ, текущий отмечен «▸»); выбор — мгновенное
  подключение; пустой список ведёт в настройки;
- **без повторного поиска при каждом запуске (v3.3)**: пульт сразу
  подключается к сохранённому ТВ; полный поиск сети — в ⚙ Настройках
  (и при самом первом запуске, пока ТВ не выбран); при возврате из настроек
  поиск не запускается заново;
- **переименование ТВ (v3.3)**: в ⚖ Настройках кнопка «✎ Переименовать
  выбранный ТВ» — своё имя сохраняется в истории и видно в списке на пульте;
- **расстановка блоков пульта drag-n-drop (v3.3)**: кнопка «✎» в шапке
  включает режим расстановки — любой блок (громкость, медиа, цифры,
  навигация, HDMI и т.д.) и большая кнопка (POWER, приложения, текст,
  тачпад…) перетаскивается долгим тапом вверх/вниз; расположение
  сохраняется; кнопка «✓» — готово;
- **автопоиск ТВ и подключение при первом запуске**: проверка сохранённого адреса →
  SSDP-поиск (UPnP) → скан подсети по портам 8001 и 55000 (Tizen и старые модели);
  если ТВ спит — пробуждение Wake-on-LAN и повторная проверка;
- **поиск ТВ — в настройках (v3.1)**: «Найти ТВ в сети»,
  выпадающий список найденных/сохранённых ТВ (старые модели помечены
  «старый протокол», но подключаются так же), IP вручную; выбранный ТВ
  сохраняется — пульт подключается сам при возврате;
- **пять тем оформления (v3.2)**: Базовый (Material, как было, свет/тьма по системе),
  **Glassmorphism** и **Неоморфизм** — каждый в светлой и тёмной версии; в
  неоморфизме текст кнопок тёмный и жирный (читаемость), у медиа-кнопок
  жёлтые иконки; выбор — в настройках, применяется сразу;
- **умная кнопка POWER**: ТВ отвечает → выключение каскадом попыток
  (`KEY_POWEROFF` → `KEY_POWER` → `KEY_POWERTOGGLE` → пара `Press`+`Release` —
  разные прошивки принимают разное; после каждой попытки проверяется, жив ли ТВ);
  ТВ недоступен → включение Wake-on-LAN (MAC из API или ARP-кэша)
  с автоматическим переподключением;
- громкость, каналы, mute; навигационный крест с OK;
- **медиа-ряд (v3.0)**: PLAY / PAUSE / STOP / REW / FF — пауза и перемотка
  в плеерах, YouTube и IPTV-приложениях;
- **цифры 0–9 + Пред. канал + Список каналов + GUIDE + INFO (v3.0)** — прямой
  ввод номера канала с телефона и ТВ-инфокнопки;
- **расширенные клавиши (v3.0)**: MENU, TOOLS, СУБТИТРЫ, МАСШТАБ, режим
  Картинки/Звука (часть клавиш зависит от прошивки — журнал покажет, что приняла);
- **«Открыть ссылку на ТВ» (v3.0)**: любая ссылка — в браузер ТВ
  (`ed.apps.launch` с payload `{url:…}`, кандидаты app-ID браузера всех
  поколений); YouTube-ссылка — экспериментально сразу в ТВ-приложение YouTube
  (Cobalt deep link), если прошивка не поддержит — пульт сам откроет её в браузере;
- **«Мои кнопки» — макросы (v3.0)**: свои кнопки на главном экране =
  приложение + последовательность клавиш (напр. «Вечерний Netflix»: запустить
  Netflix → громкость 5); тап — выполнить, удержание — редактор; хранятся per-ТВ;
- **«На ТВ: …» (v3.0)** — текущий канал/приложение в статусной строке: из
  payload-а `ms.channel.connect`, события `ms.channel.channelChanged` и
  подтверждений запуска приложений (что отдаёт прошивка — то и показывает);
- HOME / Назад / Exit; переключение входов HDMI 1–3;
- **тачпад / мышь на ТВ (v2.9)** — режим зависит от ТВ:
  - Tizen (2016+) — **настоящий курсор**: ведёте пальцем по тачпаду — указатель
    на экране ТВ повторяет движение (протокол `ProcessMouseDevice`, канал
    `ms.remote.control`); в кадр уходит **дельта сдвига** — ровно как в официальной
    библиотеке Samsung multiscreen (`currentMoveDelta`), тап по тачпаду — клик
    (`LeftClick`), **удержание — правый клик (v3.0, `RightClick`)**. Удобно
    в браузере ТВ и в приложениях с фокусом «наведи-и-нажми»;
    если прошивка игнорирует мышь — тумблер «Режим: стрелки» прямо в диалоге
    (в браузере ТВ стрелки тоже двигают указатель);
  - старые ТВ (Orsay/55000) — **режим стрелок**: свайп в сторону = перемещение
    по меню (накопительно: длинный свайп = несколько нажатий), тап = OK.
    Настоящей мыши в их протоколах нет — это честная замена;
- **список приложений с ТВ** — каскад из трёх стратегий:
  1) WS `ed.installedApp.get`;
  2) REST `GET /api/v2/applications` (полный список, если прошивка умеет);
  3) REST-проверка 28 известных приложений по ID (таблицы сообщества) —
  200 = установлено. Тап по приложению — запуск каскадом WS DEEP_LINK →
  WS NATIVE_LAUNCH → REST POST;
- ввод текста: эталонная последовательность broadcast `custom.remote.textReceived`
  → `SendInputString` → `SendInputEnd` (работает, когда на ТВ открыто поле ввода —
  например, поиск);
- журнал показывает события экранной клавиатуры ТВ (⌨ `ms.remote.imeStart`/`imeEnd`)
  — сразу видно, принимает ли ТВ текст прямо сейчас;
- включение телевизора по Wake-on-LAN (MAC берётся из API автоматически);
- встроенный журнал связи с ТВ: каждая отправленная команда и каждый ответ
  с метками времени, копирование в буфер одним нажатием;
- тест любой клавиши `KEY_*` прямо из приложения — удобно проверять имена
  кнопок без пересборки.

## Быстрый старт

1. Телефон и ТВ — в одной Wi-Fi сети.
2. Просто откройте приложение — оно само найдёт ТВ (SSDP + скан сети) и
   подключится. При первом подключении на экране ТВ появится запрос доступа —
   нажмите пультом **«Разрешить»**. Токен сохранится сам.
3. Если автопоиск не справился — введите IP вручную (Настройки → Общие →
   Сеть → Состояние сети) и нажмите «Подключ.».
4. Чтобы ТВ не спрашивал разрешение при каждом подключении: Настройки →
   Общие → Диспетчер устройств → Уведомления о доступе → **«Только первый раз»**.
5. Для включения ТВ по сети: Настройки → Общие → Сеть → **Пробуждение по сети** → Вкл.

## Диагностика (если кнопка не сработала)

Кнопка **«Журнал связи с ТВ (лог)»** внизу экрана открывает окно, где:

- `▶ К ТВ: {...}` — команда отправлена (WebSocket подтвердил передачу);
- `◀ ТВ: {...}` — ответ телевизора (кнопки ТВ не подтверждает — это норма);
- «Копировать» — выгрузить журнал в буфер обмена;
- поле с кнопкой «Отправить» — тест имени клавиши: введите `VOLDOWN`,
  уйдёт `KEY_VOLDOWN`.

Частые случаи:

- **Текст не появляется на ТВ** — текст принимается ТОЛЬКО при открытом поле
  ввода. Проверенный способ на AU9000: HOME → **Поиск** (лупа) → курсор в
  строке поиска → отправьте текст из приложения → OK на крестовине.
- **Список приложений пуст** — на Tizen 5+ Samsung отключила WS-список;
  приложение само проходит три стратегии (WS → REST-список → REST-пробы
  известных ID) и пишет код каждого запроса в журнал. Если и это не дало
  результата — пришлите журнал: по кодам будет видно, что отвечает прошивка.
- **ТВ не найден при запуске** — проверьте, что телефон и ТВ в одной сети
  (не гостевой Wi-Fi и не разные VLAN — Samsung не позволяет WS между
  подсетями), ТВ включён; или введите IP вручную.
- **Кнопка молчит, но в журнале `▶` есть** — скорее всего, у этой прошивки
  другое имя клавиши. Проверьте кандидата через тест в журнале
  (например, `VOLDOWN` вместо `VOLUMEDOWN`).
- **ТВ выключен** — нажимайте POWER ещё раз: пульт сам отправит Wake-on-LAN,
  дождётся пробуждения и подключится. На ТВ должно быть включено
  «Настройки → Общие → Сеть → Пробуждение по сети»; если MAC не определился
  автоматически — удерживайте POWER и введите его вручную.

## Как это работает

Приложение определяет поколение ТВ по открытым TCP-портам и подключается
подходящим протоколом:

- **Tizen 2016+**: `http://IP:8001/api/v2/` — информация об устройстве (без
  авторизации), отсюда берётся MAC для Wake-on-LAN; `wss://IP:8002/.../samsung.remote.control`
  (2018+, TLS, токен) или `ws://IP:8001/...` (2016–2017, без TLS) — канал пульта.
  Первое подключение без токена вызывает на ТВ запрос «Разрешить»; в ответе
  `ms.channel.connect` приходит токен, который сохраняется для каждого ТВ отдельно.
  Для `ws://8001` после подключения пульт отправляет пробные API-запросы: если ТВ
  отвечает ошибками («unrecognized method», «session of null») — это старая
  Orsay-прошивка, и пульт переходит к следующему протоколу.
- **Smart TV 2011–2015 (порт 55000)**: бинарный легаси-протокол — handshake
  `64 00` + base64-поля (описание/id/имя), клавиши — `00 00 00 + b64(KEY_…)`;
  доступ подтверждается кнопкой «Разрешить» на экране ТВ. Для моделей 2014–2015
  (H/J) есть зашифрованный вариант Smart View 2.0 — те же пакеты под
  AES-128-CBC со статическим ключом. По этим протоколам работают кнопки пульта
  и POWER; список приложений и ввод текста — только на Tizen.
- **Smart View 2.0 (порты 8080/8000, Orsay H/J)**: PIN-сопряжение —
  `POST /ws/apps/CloudPINPage` (ТВ показывает PIN) → `ws/pairing?step=0/1/2`
  (DH + AES-CBC ключом из PIN + SamyGO-трансформация → токен) → session_id;
  затем команды через socket.io `:8000` (`1::/com.samsung.companion`, кадры
  `5::…callCommon` с телом, зашифрованным AES-128-ECB токеном). По этому
  протоколу работают кнопки пульта и POWER; список приложений/текст/запуск
  приложений недоступны (прошивка не отдаёт).

Команды Tizen — JSON поверх WebSocket: `ms.remote.control` (`SendRemoteKey` —
кнопки, `SendInputString`+`SendInputEnd` — текст), `ms.channel.emit`
(`ed.apps.launch` — запуск приложений, `ed.installedApp.get` — список
приложений). На прошивках 2020+ часть WS-команд Samsung отключила, поэтому
запуск приложений и проверка установки дублируются через REST:
`POST/GET/DELETE http://IP:8001/api/v2/applications/{appId}`.

## Сборка из исходников

GitHub Actions собирает APK автоматически при каждом push (workflow
`.github/workflows/build.yml`, JDK 17 + предустановленный Android SDK
на раннере). Пуш тега `v*` дополнительно публикует Release с APK —
его подхватывает кнопка «Проверить обновления» в самом приложении.
Локальная сборка стандартная: `./gradlew assembleDebug`.

## Безопасность

Приложение отключает проверку TLS-сертификата телевизора — на ТВ стоит
самоподписанный сертификат, и в домашней сети это нормальная практика.
Не переносите этот приём на связь с внешними серверами. Токен доступа к ТВ
хранится только в локальных настройках приложения.
