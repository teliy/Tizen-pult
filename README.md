# Tizen Pult — Android-пульт для Samsung Smart TV (Tizen)

Простой пульт для телевизоров Samsung на Tizen (проверено для UE43AU9000UXRU, Tizen 5.5, 2021).
Управление по локальной Wi-Fi сети через официальный WebSocket API телевизора (порт 8002):

- громкость, каналы, mute
- навигационный крест и OK
- HOME / Назад / Exit, переключение на HDMI 1–3
- запуск YouTube и Netflix (и любых приложений из списка)
- ввод текста на ТВ
- включение телевизора по Wake-on-LAN

## Сборка APK через GitHub Actions (без Android Studio)

1. Откройте свой репозиторий `Tizen-pult` на github.com.
2. Нажмите **Add file → Upload files** и перетащите **всё содержимое** этой папки
   (папки `.github`, `app`, `gradle` и файлы в корне). Дождитесь загрузки и нажмите **Commit changes**.
3. Откройте вкладку **Actions** — там автоматически запустится сборка *Build APK*.
   Первая сборка занимает 5–10 минут.
4. Когда сборка станет зелёной, откройте её, прокрутите вниз до раздела **Artifacts**
   и скачайте **Tizen-pult-debug** (это zip с файлом `app-debug.apk`).
5. Распакуйте и откройте APK на телефоне. Android попросит разрешить установку
   из неизвестных источников — разрешите (это ваш debug-APK).

Пересборка при изменениях: просто загрузите новые файлы — Actions соберёт заново.
Сборка также запускается вручную: вкладка Actions → Build APK → **Run workflow**.

## Настройка телевизора

- Телефон и ТВ должны быть в **одной Wi-Fi сети**.
- Узнайте IP телевизора: Настройки → Общие → Сеть → Состояние сети.
- Для первого подключения приложение запросит доступ — на экране ТВ появится запрос,
  нажмите пультом **«Разрешить»**. Токен сохранится в приложении автоматически.
- Для включения ТВ по сети: Настройки → Общие → Сеть → **Пробуждение по сети (Power On with Mobile)** → Вкл.
  MAC-адрес приложение возьмёт само из API; если нет — долгое нажатие на кнопку «Включить ТВ».

## Как это работает

Телевизор Samsung Tizen слушает WebSocket API:

- `http://IP:8001/api/v2/` — информация об устройстве (без авторизации);
- `wss://IP:8002/api/v2/channels/samsung.remote.control` — канал пульта,
  авторизация одноразовым токеном после нажатия «Разрешить» на экране ТВ.

Приложение шлёт JSON-команды (`ms.remote.control` — кнопки и текст, `ed.apps.launch` — запуск приложений).

## Безопасность

Приложение отключает проверку TLS-сертификата телевизора (на ТВ стоит самоподписанный
сертификат). Это нормально для использования в домашней сети, но не используйте
похожий приём для связи с внешними серверами.

app/build.gradle                  — настройки модуля (minSdk 24, targetSdk 34)
